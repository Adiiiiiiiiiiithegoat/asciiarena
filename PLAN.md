# Hero Forge — Plan

- [x] Train mode: every pointerdown / Space adds power, drawn next frame (no dropped clicks)
- [x] Hero ladder by power: Rookie → Common → Rare → Epic → Legendary → Mythic → endless Ascended (thresholds after Common ×5)

- [x] Stickman art: gear, armor, helmets, capes, wings, auras, particles
- [x] Save progress to localStorage
